# Data Structures and Algorithms in C
This repository contains implementations of common data structures and algorithms using C.  
Focused on building problem-solving skills for technical interviews and system-level programming.

## How to compile & run
gcc filename.c -o out && ./out

## Concepts Covered 
⭐arrays/
  ▪️Traversal
  ▪️Two-pointer techniques
  ▪️Problems like move zeros
  ▪️max sub array sliding window  
⭐linked-lists/
  ▪️singly list 
  ▪️Insert/delete operations
  ▪️reverse, detect cycle, middle node
⭐stacks/
  ▪️Stack implementation using arrays
  ▪️Applications (balanced parentheses)
⭐queues/
  ▪️linear, circular queue
⭐trees/
  ▪️Binary tree basics
  ▪️Traversals (inorder, preorder, postorder)
⭐sorting/
  ▪️bubble sort
  ▪️quick/selection sort
  ▪️merge sort
⭐searching/
  ▪️linear search
  ▪️binary search
